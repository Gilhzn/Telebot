# Stock News Radar 📡

בוט טלגרם אישי שסורק את השוק האמריקאי ושולח **רק חדשות חיוביות מאוד** למניה, שניות אחרי הפרסום הרשמי:
זכייה בחוזה גדול, החברה נרכשת, אישור FDA, שותפות עם ענקית, העלאת תחזית.

הבוט הולך ישר למקורות הראשוניים, בלי ערוצי ביניים:

| מקור | תדירות |
|---|---|
| SEC EDGAR, פיד חי של 8-K ו-6-K (כולל ההודעה לעיתונות EX-99.x) | כל 2 שניות |
| PR Newswire, GlobeNewswire (RSS) | כל 10 שניות |
| מיפוי טיקרים של ה-SEC | פעם ביום |

רק מניות שנסחרות בבורסות בארה"ב (NASDAQ, NYSE, NYSE American, CBOE). ההתראות בעברית, לצ'אט פרטי אחד.

> ℹ️ מידע פומבי בלבד, לא ייעוץ השקעות. ידיעה חיובית לא מבטיחה עלייה, ומניות קטנות נוטות לקפוץ ולחזור.

## איך זה עובד

```
ידיעה חדשה → בחירת מועמדים → פסילה לפי מילים שליליות → דירוג (כללים / Claude)
          → ציון ≥ MIN_SCORE? → מניעת כפילות לטיקר (6 שעות) → טלגרם
```

- **בחירת מועמדים**: 8-K עם Item 1.01 / 2.01 / 2.02 / 7.01 / 8.01, כל 6-K, וכל הודעה לעיתונות עם טיקר של בורסה אמריקאית, למשל `(NASDAQ: OKLO)`. מניות ברשימת המעקב תמיד נבדקות.
  דיווחי EDGAR של חברות שלא רשומות בבורסה אמריקאית (OTC, חברות פרטיות) מדולגים, ותיקונים (8-K/A) לא נבדקים.
- **פסילה**: הנפקה ודילול, reverse split, אזהרות מחיקה, going concern ופשיטת רגל, תביעות ו-investor alert, הצגה מחדש של דוחות, הורדת תחזית, clinical hold ו-CRL, התפטרויות ופיטורים.
  הפסילה והדירוג בכללים נעשים על הכותרת ותחילת ההודעה, אחרי חיתוך של "About…", Forward-Looking Statements ואנשי קשר, כדי שהסתייגויות משפטיות סטנדרטיות לא יפסלו ידיעה טובה.
- **דירוג בכללים** (ברירת מחדל): כל ביטוי חיובי מוסיף נקודות (למשל `to be acquired by`, `FDA approval` = 5, `per share in cash`, `raises guidance` = 4, `awarded` = 3, לקוח ממשלתי = 2), בונוס +2 על חברת ענק ו-+1 על סכום של 100 מיליון דולר ומעלה. מקסימום 5.
- **דירוג עם Claude** (כש-`ANTHROPIC_API_KEY` מוגדר): רק ידיעות עם ציון כללים 1 ומעלה (או מניות במעקב) נשלחות ל-`claude-haiku-4-5-20251001`, עד 5 במקביל. אם הקריאה נכשלת, הבוט משתמש בציון הכללים.

### דוגמת התראה

```
🚀🚀 חיובי מאוד (+5)
OKLO | Oklo Inc.
Oklo Awarded $450 Million Contract by U.S. Department of Defense
💡 חוזה ענק ביחס לשווי החברה מול לקוח ממשלתי
📰 PR Newswire · ⏱ 8 שניות מהפרסום
למקור המלא
```

בדיווח SEC מוצגת רשימת ה-Items בעברית במקום כותרת, למשל `Item 1.01: חתימה על הסכם מהותי`.

## פקודות טלגרם

| פקודה | פעולה |
|---|---|
| `/start`, `/help` | הסבר והמצב הנוכחי |
| `/add NVDA OKLO` | הוספה לרשימת מעקב (נבדקות תמיד ועוקפות את הסינון הראשוני) |
| `/remove NVDA` | הסרה מהרשימה |
| `/list` | הצגת הרשימה |
| `/status` | זמן פעילות, ידיעות שנבדקו, קריאות AI, ומצב כל מקור (✅/❌) עם זמן העדכון האחרון |
| `/test` | התראת דוגמה |

הבוט מגיב רק ל-`TELEGRAM_CHAT_ID`. אם המשתנה ריק, הבוט ננעל על הצ'אט הפרטי הראשון ששולח לו הודעה (Start) ושומר את המזהה ב-`.env`.

## הרצה מקומית

דורש Python 3.12 (עובד גם על 3.10 ומעלה).

```bash
# 1. טוקן: @BotFather → /newbot  (אם טוקן נחשף אי פעם: /revoke והנפקה מחדש)
cp .env.example .env        # למלא TELEGRAM_BOT_TOKEN ו-SEC_USER_AGENT
pip install -r requirements.txt

python bot.py --test        # בודק טוקן, מזהה ושומר chat id, שולח התראת דוגמה
python bot.py               # הרצה רציפה
```

בהפעלה נשלחת הודעת "פעיל". בהרצה הראשונה כל מה שכבר קיים בפידים מסומן כ"נראה" בלי שליחה, כדי לא להציף.

## הגדרות

כל ההגדרות ממשתני סביבה, או מקובץ `.env`. רק שלושת הראשונים חובה.

| משתנה | ברירת מחדל | תיאור |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | חובה | טוקן מ-@BotFather |
| `TELEGRAM_CHAT_ID` | ריק | ריק = זיהוי אוטומטי בלחיצה על Start. חובה במצב `--once` |
| `SEC_USER_AGENT` | חובה | שם ואימייל, דרישה של ה-SEC |
| `ANTHROPIC_API_KEY` | ריק | מפעיל דירוג עם Claude |
| `ANTHROPIC_MODEL` | `claude-haiku-4-5-20251001` | המודל לדירוג |
| `POSITIVE_ONLY` | `true` | `false` = כל הדיווחים של מניות ברשימה, בלי דירוג |
| `MIN_SCORE` | `4` | סף השליחה, מ-5- עד 5 |
| `MARKETWIDE` | `true` | סריקת כל השוק. `false` = רק רשימת המעקב |
| `WATCHLIST` | ריק | רשימה התחלתית מופרדת בפסיקים (נטענת רק כשאין עדיין state) |
| `CANDIDATE_ITEMS` | `1.01,2.01,2.02,7.01,8.01` | Items ב-8-K שנבדקים |
| `EDGAR_FORMS` | `8-K,6-K` | סוגי דיווחים |
| `EDGAR_POLL_SECONDS` | `2` | תדירות דגימת EDGAR |
| `WIRE_POLL_SECONDS` | `10` | תדירות דגימת הוואיירים |
| `WIRE_FEEDS` | PR Newswire, GlobeNewswire | כתובות RSS מופרדות בפסיקים |
| `DEDUP_HOURS` | `6` | חלון מניעת כפילות לטיקר |
| `MAX_ALERTS_PER_CYCLE` | `15` | תקרת מועמדים למחזור לכל מקור |
| `STATE_FILE` | `state.json` | נתיב קובץ המצב |

## פריסה

| | שרת (Railway / Oracle) | GitHub Actions |
|---|---|---|
| עיכוב התראה | 2 עד 10 שניות | 5 דקות ומעלה |
| פקודות טלגרם | מיידי | רק בכל הרצה |
| עלות | Oracle חינם, Railway כ-5$ לחודש | חינם בריפו ציבורי; בריפו פרטי לבדוק מול מכסת הדקות |

**המלצה: שרת.** זו הדרך היחידה לעמוד במטרה של "לפני כולם".

### Railway
New Project → Deploy from GitHub repo. ב-Variables להגדיר את הסודות ו-`STATE_FILE=/data/state.json`, ולהוסיף Volume בנתיב `/data`. פקודת ההרצה מגיעה מ-`Procfile` (`python bot.py`).

### Oracle Cloud (או כל שרת Ubuntu)
למלא את המשתנים בראש `oracle-cloud-init.sh` ולהדביק אותו כ-cloud-init ביצירת המכונה (Ubuntu 24.04), או להריץ `sudo bash oracle-cloud-init.sh` על מכונה קיימת.
הסקריפט מבצע `git clone` מהריפו, מתקין venv ושירות systemd (`journalctl -u stock-news-radar -f` ללוגים). הרצה חוזרת מושכת את הקוד העדכני ומפעילה מחדש.

### GitHub Actions (מצב `--once`)
`python bot.py --once` טוען את `state.json`, מטפל בפקודות טלגרם שממתינות, עובר פעם אחת על כל המקורות, ממתין לסיום הדירוג, שומר ויוצא. בלי הודעת הפעלה ובלי זיהוי אוטומטי של chat id.

ה-workflow ב-`.github/workflows/radar.yml` רץ כל 5 דקות ושומר את `state.json` בקומיט. הוא **כבוי כברירת מחדל**, כדי שלא ירוץ במקביל לשרת (שני קבצי מצב = התראות כפולות). כדי להפעיל:
1. Settings → Secrets and variables → Actions → Secrets: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `SEC_USER_AGENT`, ואופציונלית `ANTHROPIC_API_KEY`.
2. באותו מסך, בלשונית Variables: `RADAR_MODE` = `actions`.

סיכון: פיד RSS מחזיק רק עשרות פריטים אחרונים, ובשעות העומס הודעות עלולות לגלוש מהפיד בין הרצה להרצה. פיד EDGAR מחזיק 100 פריטים לכל סוג, וזה מספיק ל-5 דקות.

## בדיקות

```bash
python -m unittest discover -s tests -v
```

הבדיקות רצות בלי רשת (httpx MockTransport) ומכסות: מנוע הכללים והפסילה, בחירת EX-99.1, חילוץ טיקרים, צינור מלא (אתחול בלי שליחה, כפילות, הפעלה מחדש), Claude מדומה כולל נפילה לכללים, חסימת SEC, ETag, פקודות, זיהוי chat id, `--test` מול 401/400/403, ומצב `--once`.

## אבטחה ותאימות

- סודות רק ב-`.env` (ב-`.gitignore`), במשתני השרת או ב-GitHub Secrets. לעולם לא בקוד.
- טוקן שנחשף: `/revoke` ב-@BotFather והנפקת טוקן חדש לפני העלאה לריפו.
- SEC: User-Agent מזוהה, עד ~7 בקשות בשנייה בסך הכול, והמתנה של 10 דקות על 403/429.
- מקור שנכשל מסומן ב-❌ ב-`/status`, ושאר המקורות ממשיכים לעבוד.
